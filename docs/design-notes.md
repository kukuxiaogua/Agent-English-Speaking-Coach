# 陪练规则的设计笔记

整理于 2026-09-12。本页提炼自早期个人陪练中的规则调整和记录方式，省略个人身份、工作安排、账户信息和真实对话原文。这里记录设计依据，不宣称这些调整已经得到实验验证。

## 从问题到规则

| 遇到的问题 | 当前规则 | 后续可以观察什么 |
| --- | --- | --- |
| 问题太长，学习者难以判断先回答哪部分 | 一次一个短问题；必要时改用简单英语或例子 | 请求解释后能否继续交流；不要把助手提问失误直接计为听力错误 |
| 当场连续纠错打断想表达的内容 | 话题结束后选少量修正，每处只在新例子中尝试一次 | 是否完成新例子、能否继续原话题；不无限重复跟读 |
| 追问来源被误判为回答练习题 | 先确认用户意图，回答来源问题，再给语言反馈 | 是否区分了回答、澄清和质疑；误判能否被记录并撤回 |
| 把旧笔记、个人经历和虚构情景混在一起 | 标明实际读到的来源及日期，明确标注虚构练习 | 读者能否知道一句话属于事实、意见还是练习设定 |
| 只有转写，却对发音或整体水平下结论 | 记录输入形式及支持程度，缺少证据就不评分 | 是否保留真实样本、说明帮助和未知信息 |
| 下次练习重新访谈，或重复已完成内容 | 每次记录下一步的具体动作，开始前读取最新复盘 | 下一次能否从指定位置继续，已完成练习是否被重复 |
| 将整段通话直接算成有效练习时间 | 区分通话时长和有效练习，只扣除测量过的等待 | 时间来源是否明确；缺失计时是否如实标注 |

## 为复用所做的简化

公开版只保留三类学习文件：档案保存长期偏好，周计划保存任务状态，每日复盘保存本次细节和下次起点。删除固定周次、固定时区、固定每日时长，以及对个人定时任务的依赖。

开始时没有历史记录，就初始化；跨周没有计划，就在当前对话里生成。断线后只从可见历史恢复已知内容。没有可靠时间或音频时保留未知，不增加猜测性的补全步骤。

## 如何继续迭代

遇到问题时，先保存去掉个人信息的最小片段，写清楚预期和实际行为，再只调整相关规则。用下一次相似情景观察调整是否有帮助，记录助手提供的提示和材料差异；不同条件下的结果不直接换算成进步百分比。

如果一条规则增加了流程，却没有帮助交流或记录，就考虑删除。等手动流程稳定、重复工作确实出现后，再考虑定时任务或其他自动化。

## 当前验证边界

这套文件已做静态结构与一致性检查。虚构示例只解释文件格式；它们不是试用记录。独立文件夹里的首次设置、真实语音结束后的保存，以及后续接续体验仍需要实际试用。其他客户端的兼容性也尚未验证。
